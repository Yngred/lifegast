# LifeGast 

Site simples de controle financeiro pessoal, feito em HTML, CSS e JavaScript puro (sem frameworks).

## Funcionalidades

- Cadastro de transações (receitas e despesas)
- Cálculo automático de saldo, total de receitas e total de despesas
- Modo compartilhado: cadastre os membros que contribuem com a renda da casa e veja se o dinheiro do mês fechou
- Todos os dados ficam salvos no navegador (localStorage) — não precisa de servidor ou banco de dados

## Como usar

1. Baixe ou clone este repositório
2. Abra o arquivo `index.html` no navegador (ou use a extensão "Live Server" do VS Code)
3. Clique em **+ Adicionar transação** para registrar receitas e despesas
4. Clique em **Configurações** para colocar seu nome e os membros que contribuem com a renda

## Tecnologias

- HTML5
- CSS3
- JavaScript (Vanilla)
- localStorage (armazenamento no navegador)

## Rodando localmente

```bash
git clone https://github.com/Yngred/lifegast.git
cd lifegast
```

Depois é só abrir o `index.html` no navegador.
